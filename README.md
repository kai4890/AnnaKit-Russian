# Анна Кит — русская версия портфолио

Независимая копия AnnaKit-Cloudflare. Интерфейс, тексты и описания фотографий переведены на русский язык. Упоминания о проживании в Австралии удалены. Контактные адреса и исходные медиаматериалы сохранены.

## Локальный просмотр

```sh
python3 scripts/serve.py --port 4175
```

Откройте http://127.0.0.1:4175.

## Сборка

```sh
python3 scripts/build.py
```

Готовые статические файлы находятся в `dist/`. Сборка обновляет список изображений из `photography/`, сохраняя русские описания.

Пресс-релизы открываются на русском языке. Английские переводы доступны через переключатель. Встроенные публикации Instagram, видео и исходные PDF сохраняют язык оригинала.

Для отдельного развёртывания на Cloudflare задано имя Worker `annakit-russian`. Этот проект не опубликован; исходный сайт не изменён.
